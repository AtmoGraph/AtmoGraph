# AtmoGraph Frontend

React and D3.js dashboard for the AtmoGraph Supply Chain Ripple Effect Predictor.

## Week 1 Features

- Responsive supply-chain monitoring dashboard
- Static global supply-chain network rendered with D3.js
- Selectable nodes with supplier and location details
- Risk indicators for stable, watch, and critical nodes
- Active disruption and exposure summaries
- Node and location search
- Static demonstration data for frontend validation

## Technology

- React
- Vite
- D3.js
- Lucide React
- Oxlint
